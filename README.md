# El-Chubbo — Resume & Portfolio Site

A simple, dark-themed single-page portfolio built with plain HTML, CSS, and zero dependencies.
Hosted for free on **GitHub Pages**.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure (About, Skills, Projects, Contact) |
| `styles.css` | Dark theme styling |

## Deploy to GitHub Pages
1. Push this folder to a GitHub repo named `El-Chubbo.github.io` (or `el-chubbo.github.io`).
2. Go to **Settings → Pages → Source: main branch**.
3. Visit `https://El-Chubbo.github.io`.

## Customize
- Edit your name, role, and bio in the `hero` section.
- Update the `Skills` cards with your real languages/tools.
- Replace `Project One/Two/Three` with your real repos and links.
- Swap the email and GitHub links in the `contact` section.
